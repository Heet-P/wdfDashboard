# Product Overview

## Personal WDF Lab Dashboard Website

A personal portfolio and Web Development Framework (WDF) practical dashboard built for academic purposes. The website showcases student practicals in an interactive, visually appealing format with both student and professor views.

### Core Features
- **Interactive Timeline**: Animated chronological display of practicals with parallax scrolling
- **Dashboard Grid**: Card-based overview of all practicals with preview images
- **Dual Access Modes**: Student view (public) and Professor view (authenticated)
- **Theme Support**: Light/dark mode toggle with persistent preferences
- **Responsive Design**: Mobile-first approach supporting all device sizes
- **Accessibility**: WCAG compliant with keyboard navigation and ARIA labels

### Target Users
- **Students**: View and navigate their completed practicals
- **Professors**: Review student work and provide feedback (authentication required)
- **Academic Institutions**: Showcase student portfolios and track progress

### Design Philosophy
- **Glassmorphism Aesthetic**: Modern blur effects with rounded corners and transparency
- **Performance First**: Vanilla JavaScript with no external frameworks
- **Educational Focus**: Clear presentation of learning progression and achievements
